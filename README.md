### Where it started

I didn't set out to be a developer — I set out to fix things, mostly things that weren't broken. That habit turned out to be the whole job. Java in 2019 was the first real spark; the 2020 lockdown is what actually pulled me into web development, one confused `console.log` at a time. Everything since then has been the slow, ongoing process of turning *"I can make a webpage"* into *"I can make a system."*

<br>

### How I build things today

I work in Angular on the front end and NestJS on the back, with TypeScript holding the seams together so I don't have to trust myself at midnight. I care about the parts of a project nobody asks about in an interview — folder structure, naming, the decision that makes the next person's life easier six months from now. Usually that next person is me, which is its own kind of motivation.

I'd rather spend an extra hour getting the architecture right than ship something fast and regret it later. Not always the efficient choice. Almost always the right one.
